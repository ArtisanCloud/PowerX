## 用户场景与测试（必填）

### 主要用户故事

作为后台运营或内容管理员，我希望在同一个后台中上传、搜索、更新和下架媒体资产，并为业务团队生成临时访问链接，以便高效管理图片和视频等资源。

### 验收场景

1. **前提** 管理员已具备后台访问权限并且存储驱动已正确配置，**当** 管理员上传本地文件或提供外部文件 URL 时，**那么** 系统应校验请求、保存媒体元数据并返回可访问的资源信息。  
2. **前提** 管理员需要查找历史素材，**当** 管理员在媒体列表中按关键字、存储驱动或归属主体进行筛选时，**那么** 系统应返回分页结果及总记录数，并允许查看详情信息。

### 边界情况

- 如果创建请求既无文件又无有效外部链接，系统应拒绝该操作并提示缺少可用资源。  
- 如果管理员尝试访问已软删除或禁用的资源，系统应阻止访问并提示资源不可用。  
- 上传大小限制由各自的存储驱动决定；当驱动拒绝超出限制的请求时，管理员应收到明确的错误提示。

## 需求（必填）

### 功能性需求

- **FR-001**：允许已授权的管理员通过本地上传或可信外部链接创建媒体资产；记录名称、驱动、目录、归属主体和可选标签等字段，并将存储驱动返回的错误（如大小限制）清晰反馈给用户。  
- **FR-002**：在操作前验证所选存储驱动处于启用状态；若缺失或被停用，应拒绝操作并返回明确原因。  
- **FR-003**：提供媒体资产分页列表，支持关键字、驱动类型、归属主体（类型与 ID）、可选标签的筛选，并返回满足条件的总数。  
- **FR-004**：提供媒体资产详情页，展示基础元数据、创建/更新时间、业务状态及基于驱动生成的访问 URL（如带有效期的预签名链接）。  
- **FR-005**：允许管理员更新业务属性（名称、描述、标签、业务状态：草稿 / 审核中 / 已发布 / 已归档），但不得更改底层存储位置或驱动配置。  
- **FR-006**：支持软删除并记录操作者与时间；默认采用“立即软删除 + 定时清理物理文件”的策略，如策略要求立即物理删除，则执行完文件清理后返回结果。  
- **FR-007**：支持为已有或待上传的资源生成带有效期的预签名链接；默认有效期为 12 小时，且仅授权管理员可生成。  
- **FR-008**：所有上传、更新、删除、预签名操作需留下可审计日志，用于追踪操作者、来源及参数。

---

### 关键实体

- **媒体资产**：平台管理的单个文件或外部资源，包含名称、存储驱动、访问 URL、文件大小、归属主体、标签、业务状态（草稿 / 审核中 / 已发布 / 已归档）、时间戳及软删除标识。  
- **存储驱动**：系统可用的存储选项（本地文件系统或兼容 S3 协议的对象存储），包含驱动标识、可用状态、基础访问路径与预签名配置。  
- **预签名请求**：上传或下载的临时授权，包含目标资产 ID、链接类型（上传/下载）、有效期、允许的 HTTP 方法以及需返回给前端的附加字段。

---

## 前置假设与依赖

- 系统已具备后台身份验证与授权机制，确保仅识别身份的用户可访问相关接口。  
- 存储驱动的基础配置（Bucket、访问密钥、基础 URL）由运维或配置中心预先维护；媒体模块依赖这些配置运行。  
- 业务方已建立统一的标签与归属主体编码标准，媒体资产创建或更新时需遵循。  
- 系统存在由运维维护的定时任务，用于周期性清理软删除状态的文件并执行物理删除。  
- 最大上传文件大小由各存储驱动控制，后台不会额外设定统一上限。
