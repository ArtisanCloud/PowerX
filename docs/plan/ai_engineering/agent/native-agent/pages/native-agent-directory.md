# 页面设计：智能体管理中的模板/克隆视图

## 1. 目标

在现有智能体管理中展示可作为克隆来源的智能体，帮助租户从 PowerX 内置智能体、插件智能体或租户已有智能体开始创建自己的智能体。

该视图不是独立的“智能体模板包管理页”。智能体模板包只作为后台快照、版本、来源和克隆预览存在；用户看到和操作的是智能体。

## 2. 路径

建议复用：

`/settings/ai/agents`

可通过 Tab 或筛选进入“可克隆来源”视图。

## 3. 页面布局

顶部：

- 搜索框：按智能体名称、职位、行业、插件来源搜索。
- 筛选：来源类型、职位、行业、状态、是否推荐。
- 操作：刷新、查看已启用智能体。

列表：

- 智能体名称
- 来源：PowerX 内置、租户已有、插件市场、外部导入
- 职位分类
- 可叠加行业
- 默认 Skill Pack 数
- 默认 Workflow Pack 数
- 默认知识库类型
- 状态

操作：

- 查看详情
- 克隆智能体
- 预览 Skill/Workflow
- 配置知识库
- 配置权限

## 4. 规则

1. 该视图展示可克隆智能体，不展示或维护独立模板包对象。
2. 克隆动作必须进入创建向导，不在列表中一键创建。
3. Workflow runtime 未启用时，只显示 Workflow 依赖预览，不显示可执行状态。
4. 模板包字段只能在来源、版本、克隆预览、调试和审计区域出现。
5. 列表主标签必须使用智能体业务名称，不显示 UUID、template key 或 capability id。
