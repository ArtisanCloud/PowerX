# PowerX 原生智能体目录

## 1. 目录原则

原生智能体按企业职位优先设计。每个内置智能体都可以叠加行业扩展和企业自定义扩展。内置智能体背后可以由模板包快照承载，但目录里展示的是智能体，不是单独的模板包对象。

每个智能体标准配置：

- 默认 Knowledge Space Profile
- 默认 Skill Pack
- 默认 Workflow Pack
- 默认 Metadata Template
- 默认权限边界
- 推荐页面入口

## 2. 通用专家知识库策展智能体

名称：专家知识库策展智能体

职责：

- 接收专家日常输入。
- 把文字、图片、录音和文件转为结构化知识草稿。
- 识别方法论、案例、SOP、决策规则和知识冲突。
- 协助专家审核并发布到绑定知识库。

默认绑定：

- Knowledge Space Profile：`expert_personal_knowledge`
- Skill Pack：`knowledge.ingestion.basic`、`knowledge.curate.methodology`
- Workflow Pack：`expert_knowledge_daily_capture`
- Metadata Template：通用知识对象骨架

## 3. CEO/经营管理智能体

职责：

- 汇总经营数据、战略材料、管理复盘和关键决策。
- 帮助沉淀企业经营方法论和决策原则。
- 支持 CEO/管理层做复盘、判断和方案生成。

默认知识结构：

- 战略
- 经营
- 组织
- 决策
- 风险

## 4. 财务智能体

职责：

- 沉淀财务分析方法、预算规则、风控规则和经营指标解释。
- 支持预算分析、费用复盘、现金流判断和异常解释。

默认知识结构：

- 报表
- 预算
- 风控
- 税务
- 经营分析

## 5. 营销智能体

职责：

- 沉淀品牌、市场、增长、渠道、内容和投放方法论。
- 支持营销方案生成、Campaign 复盘和客户转化策略分析。

默认知识结构：

- 战略层
- 策略层
- 执行层
- 复盘层

## 6. 运营智能体

职责：

- 沉淀 SOP、流程、指标、异常处理和复盘经验。
- 支持运营方案、流程优化、质量控制和效率提升。

默认知识结构：

- 流程
- 指标
- 异常
- SOP
- 复盘

## 7. 销售/客户成功智能体

职责：

- 沉淀客户画像、销售话术、异议处理、续费策略和成功案例。
- 支持销售陪练、客户方案和流失预警分析。

默认知识结构：

- 客户画像
- 话术
- 异议
- 案例
- 续费

## 8. HR/组织智能体

职责：

- 沉淀岗位模型、招聘标准、绩效规则、组织制度和培训材料。
- 支持招聘筛选、绩效复盘、组织诊断和培训问答。

默认知识结构：

- 岗位
- 招聘
- 绩效
- 制度
- 培训

## 9. 产品智能体

职责：

- 沉淀需求、用户反馈、产品决策、路线图和竞品分析。
- 支持需求澄清、PRD 草拟、反馈归类和版本复盘。

默认知识结构：

- 用户
- 需求
- 方案
- 版本
- 竞品

## 10. 法务/合规智能体

职责：

- 沉淀合同条款、合规规则、风险案例和审查清单。
- 支持合同初审、风险提示、合规问答和审计准备。

默认知识结构：

- 合同
- 合规
- 风险
- 审查
- 案例

## 11. 行业扩展叠加

行业扩展不创建新的主智能体，而是叠加到上述职位智能体的来源快照：

| 行业扩展 | 影响内容 |
| --- | --- |
| 金融 | 风险、合规、投研、客户适当性 |
| 零售 | 门店、会员、库存、活动 |
| 制造 | 工艺、质量、设备、供应链 |
| 教育 | 课程、学员、教学、转化 |
| 医疗 | 规范、质控、患者教育、合规 |
| 专业服务 | 项目、交付、知识复用、客户案例 |
