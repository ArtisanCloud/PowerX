# 页面设计：智能体管理

## 1. 目标

展示租户实际拥有和运行的智能体，包括从内置智能体克隆、自建、插件导入和外部导入的智能体。

这是 native-agent 的用户主入口。用户在这里管理智能体和智能团，不进入单独的智能体模板包管理页。

## 2. 路径

`/settings/ai/agents`

## 3. 页面布局

顶部：

- 搜索框：按智能体名称、owner、来源名称搜索。
- 来源筛选：PowerX 内置克隆、租户自建、插件市场、外部导入。
- owner 筛选：租户、部门、用户、项目、客户。
- 职位/行业筛选。

列表：

- 智能体名称
- 来源
- owner
- 绑定知识库
- Skill 状态
- Workflow 状态
- 权限状态
- 最近运行
- 状态

操作：

- 新建智能体
- 克隆智能体
- 从插件市场导入
- 配置知识库
- 配置权限
- 退役/只读

## 4. 详情 Tab

- 总览
- Persona/Prompt
- Skill
- Workflow
- 知识库
- 元数据模板
- 权限
- 运行与审计
- 来源与继承

## 5. 规则

1. 该页面是运行态智能体管理主入口。
2. 同类智能体允许重复存在。
3. 列表主标签显示业务名称，不显示 UUID。
4. 数字分身应显示 owner 用户或部门。
5. 智能体模板包只作为克隆来源和配置快照，不作为该页面上的独立维护对象。
