# 页面设计：专家知识库工作台

## 1. 目标

让专家、岗位负责人或知识运营人员持续提交材料，并把材料转为可审核、可发布的知识库内容。

## 2. 路径

`/agent/knowledge-curator`

## 3. 输入区

支持：

- 文字输入
- 文件上传
- 图片上传
- 录音上传
- 链接提交

每个输入都必须生成 source asset，并保留来源、上传人和时间。

## 4. 目标知识库

选择器：

- 可搜索 Knowledge Space。
- 支持按 owner scope 过滤。
- 显示知识库名称、owner、状态。
- UUID 只在调试区显示。

## 5. 处理流程

用户选择：

- Workflow 模板
- 行业扩展/智能体来源
- 审核人

如果 Workflow runtime 未启用，则阻止提交处理并显示缺失依赖；不得切换到 Skill + Task Queue 替代流程。

## 6. 草稿审核

草稿分区：

- 新增知识
- 待合并知识
- 冲突知识
- 建议废弃知识

每个草稿必须显示：

- 来源材料
- 抽取结果
- 分类/标签建议
- 影响的旧知识
- 发布动作

## 7. 发布记录

展示：

- 版本号
- 审核人
- 来源材料
- 发布时间
- 回滚入口
