# 主机概览观测边界

入口：监控中心 → 主机概览，路由 `/monitor/host`；`/monitor` 同样进入该概览。

## 接口与权限

`GET /api/v1/admin/monitor/host` 仅允许平台 Root 用户会话。接口返回统一 `data` 包装、`Cache-Control: no-store`，不读取业务数据库，不开放插件、服务 API Key 或 Agent 委托调用。不接受任意采集路径或命令。正式能力目录不发布该接口；能力审计 ignore 中明确记录 Root 运维范围。

初次载入或手动刷新采集一次，不设周期轮询、后台指标进程或 Loki 依赖。只读采集部分失败时保留其余指标，缺失值为 null，不冒充 0。

## 指标口径

- CPU：短时间窗口的系统利用率及逻辑核心数；不是历史平均或进程利用率。
- 内存与 Swap：系统可见总量、可用量和已用量。Linux 内存可用量取 MemAvailable，避免把可回收缓存全部误计为不可用内存。
- 磁盘：进程挂载命名空间内可见的挂载点，容量为文件系统视角，不对同一卷多个挂载点求和。已用与普通用户可用可能因保留块而不等于总量。
- 网络：网卡地址和累计收发字节数，不把累计数标为实时速率。
- GPU：当前提供 NVIDIA nvidia-smi 有界只读采集；驱动缺失、非 NVIDIA 设备或不支持采集时明确标为不可用，不能据此断言设备没有 GPU。
- 容器：标注容器可见视角，CPU、内存可能是宿主机全局可见值；不是 cgroup 配额，也不是容器外宿主机清单。

Linux 读取固定 proc 文件和挂载统计；macOS 使用固定只读系统命令及挂载统计。其他平台不支持的项目明确降级。外部命令有超时与输出上限，不调用 shell。远程挂载不能因失联阻塞整个观测请求。

## 页面行为

概览优先展示关键指标、采集时间及异常。桌面左侧任务导航，窄屏横向导航；计算与内存、磁盘、网络、GPU 分区一次只显示一项。切换分区保留同一快照，不重新请求。刷新失败保留旧快照并明确标注过期；切换用户或租户身份时清除旧快照，旧请求不得回写新身份界面。

磁盘处理入口链接已有存储治理，不在本页提供删除、归档、扩容或重启操作。观测数据和平台 API 可用不代表清理执行或 GPU 驱动验收。

## 部署

新增接口和动态菜单需要部署 Core 后端；新页面需要部署 web-admin。源码和隔离测试不等于日常运行服务已升级。用户启动的服务由用户按原配置重新编译、重启，Agent 不代为停止或重启。

### 网络可读性与 macOS 计数修正

网络默认展示已启用且有可用 IP 的连接卡片，明确累计接收／发送方向；回环、停用和未分配 IP 的接口放在全部接口详情中，不将未分配 IP 单独标为采集故障。接口启用不等同于互联网已连通。旧后端未上报启用状态时明确显示状态未上报。

修正 macOS netstat 在缺少硬件地址时的列偏移，并去掉停用接口名尾部的星号。已用真实 macOS 采集确认回环收发值均存在、非零且相等，避免把数据包数量或冲突计数误当字节。该修正需要重新编译并重启 Core 后端生效。当前前端单测为 14 项，三宽度浏览器验收包含接口详情展开与选中分区一致性。

### 默认磁盘范围与镜像告警

系统盘、数据盘和外接数据盘保留默认观测。CoreSimulator 镜像、ISO/UDF/squashfs 系统镜像、已知系统内部挂载以及非根目录的只读挂载默认收进“查看全部挂载”，不触发容量告警。只读系统根卷仍显示但不告警；macOS 可写 Data 卷保留。按照挂载用途分类，不按照是否运行在虚拟机分类，虚拟机 guest 的实际系统盘与数据盘仍监控。

后端新增可选 read_only 字段，直接读取系统文件系统标记；该标记随 Core 后端重新编译、重启后生效。前端已兼容旧快照，对已知 CoreSimulator 镜像路径无需等待新字段即可正确过滤。

本次 17 项前端单测及三宽度浏览器流程通过，后端测试与 Linux 交叉编译通过；真实 macOS 采集确认两个模拟器挂载均为只读。未卸载、删除任何镜像或改动用户启动的服务。
