> 操作建议：每个问题关闭时追加「修复说明 / 证据」并勾选复选框。

### Auth & IAM

- **ISS-001｜OIDC 登录流（授权码+PKCE+Silent Renew）** — **❌ 未实现**
    - 症状：缺回调页 `/auth/callback`、静默续期页 `/auth/silent-renew` 与 `oidc-client-ts` 集成。
    - 影响：跨系统 SSO、会话续期不可用。
    - 方案：新增 `plugins/oidc.client.ts`，对接文档《OIDC_SSO_and_Session_Flow.md》。
    - ✅修复说明 / 证据：
        - [ ] PR 链接：
        - [ ] 配置：`OIDC_*` env 变量、回调 URL 生效截图。

- **ISS-002｜菜单过滤 & 路由权限守卫一致性** — **⚠️ 部分实现**
    - 症状：零散 `isRoot` 判断，未统一基于 `meta.perms` 进行菜单/页面/按钮控制。
    - 方案：实现 `v-perm` 指令、菜单渲染时基于权限白名单过滤。
    - ✅修复说明 / 证据：
        - [ ] 代码：`directives/perm.ts`、`plugins/perm.ts`
        - [ ] 截图：无权限账号访问某页面 → `/forbidden`。

- **ISS-003｜Token 轮转 & 跨标签同步** — **⚠️ 部分实现**
    - 症状：过期刷新策略与 BroadcastChannel 未实现。
    - 方案：在 OIDC 到期前 T-60s 刷新；`BroadcastChannel('px-auth')` 同步登出/令牌。
    - ✅修复说明 / 证据：
        - [ ] 代码：`plugins/broadcast.client.ts`
        - [ ] 多标签联动视频/动图。
