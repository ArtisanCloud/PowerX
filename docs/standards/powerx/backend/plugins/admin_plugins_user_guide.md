# 插件应用市场与已安装管理（前端操作手册）

适用对象：
- 平台管理员（root）
- 租户管理员（Tenant Admin）

目标：指导在 PowerX Admin 中，如何使用“应用市场”和“已安装”两类页面完成插件的安装、启停、版本管理与租户级启用/凭证管理。

---

## 角色与权限

- 平台管理员（root）
  - 可见：应用市场、已安装、插件详情、运行日志/状态、版本管理。
  - 可做（系统级）：安装/卸载、切换版本、启用/停用进程、重启。
  - 可做（租户级）：在“默认租户”或切换到任一租户后，执行本租户启用/停用、轮换密钥、删除租户配置。
- 租户管理员（Tenant Admin）
  - 可见：应用市场（仅浏览）、已安装（本租户视角）。
  - 可做（租户级）：本租户启用/停用、查看 client_id、轮换密钥、删除本租户配置。
- 普通成员（Member）：不显示插件管理入口。

提示：系统级操作仅 root 可见；租户级操作需当前页面具备有效租户上下文（顶部租户选择器）。

---

## 页面导航与布局

- 顶部：租户选择器（root 可切换任一租户）。
- 左侧菜单：
  - “应用市场（Marketplace）”
  - “已安装（Installed）”

### 应用市场（Marketplace）
- 用途：浏览“可安装插件”目录；root 可发起安装。
- 列表项字段（示例）：图标、名称、分类、作者、版本、标签、描述、系统状态标记（已安装/未安装）。
- 过滤：按分类、标签、关键字搜索；状态筛选（已安装/未安装）。
- 操作按钮：
  - root：未安装 → “安装（系统级）”；已安装 → “管理”。
  - Tenant Admin：仅“管理”。

### 已安装（Installed）
- 用途：查看系统已安装插件的全局状态 + 当前租户状态。
- 行内字段：
  - 系统级：名称、版本、系统状态（installed/enabled/disabled）、运行态摘要（running/unhealthy/stopped）。
  - 租户级（当前租户）：是否存在配置（exists）、启用状态（enabled）、client_id（只读）。
- 行内操作：
  - root（系统级）：启用/停用、重启、切换版本、卸载、查看日志/状态。
  - Tenant Admin（租户级）：启用/停用本租户、查看 client_id、轮换密钥、删除本租户配置。
- 详情抽屉（可选）：点击行或“详情”打开，展示元数据、菜单、RBAC 资源、运行态、安装路径等。

## 操作流程

### 1) 安装插件（系统级，root）
1. 进入“应用市场”。
2. 在目标插件卡片上点击“安装（系统级）”。
3. 安装来源：
   - 本地目录：选择打包产物目录 `dist/<version>`。
   - 远程 URL：填写下载地址与校验信息（如 sha256）。
4. 提交后，系统完成“注册表登记 + 磁盘落地”，可选立即“启用（系统级）”。
5. 安装成功后，前往“已安装”页查看状态。

注意：安装是系统级行为，与租户无关；不会生成租户凭证。

### 2) 启用/停用（系统级，root）
1. 打开“已安装”页，找到目标插件。
2. 点击“启用（系统级）”启动进程并挂载反代；或点击“停用（系统级）”停止进程并卸载反代。
3. 状态区显示运行态（running/unhealthy/stopped）、健康统计与端口等。

提示：系统级启停影响所有租户的连通性，但不影响租户侧 enabled 开关与凭证记录。

### 3) 启用本租户（首次生成凭证）
1. 确认插件“系统级已安装”并“进程可用”（建议系统级启用）。
2. 切换到目标租户（顶部选择器）。
3. 在“已安装”页目标行点击“启用本租户”。
4. 首次启用成功后，会弹出“一次性密钥展示”对话框：
   - 展示 `client_id` 与 `client_secret`（明文仅此一次）。
   - 请立即复制并安全保存到插件侧配置（ENV/密钥管理器/私有配置文件）。
5. 关闭弹窗后，本租户状态显示为“已启用”。

### 4) 停用本租户
1. 在“已安装”页目标行点击“停用本租户”。
2. 停用仅影响本租户访问，不删除凭证记录，后续可随时重新启用。

### 5) 轮换密钥（本租户，高危）
1. 在“已安装”页目标行点击“轮换密钥”。
2. 确认提示：“旧 secret 立即失效，未更新的插件调用将失败”。
3. 提交后弹出新 `client_secret`（仅此一次展示），请立刻更新插件侧配置。

### 6) 删除本租户配置（高危）
1. 在“已安装”页目标行点击“删除本租户配置”。
2. 确认提示：“删除后本租户将无法访问该插件，需重新启用生成新密钥”。
3. 确认后删除凭证记录；行内状态回到“未启用（本租户）”。

### 7) 切换版本 / 卸载（系统级，root）
- 切换版本：
  1. 在目标行或详情页选择目标版本，点击“切换版本”。
  2. 可选“切换后立即启用”。
- 卸载：
  1. 点击“准备卸载”进入 drain，系统会停止目标插件新增使用入口。
  2. 等所有受影响租户实例进入 `drained` 后，点击“最终卸载”。
  3. 可选“同时清理磁盘产物（purge）”。
  4. 卸载会影响所有租户对该插件的使用；请谨慎操作。

卸载边界必须明确：

1. 插件卸载是目标插件的生命周期操作，不是 PowerX 底座重启。
2. `drain`、`最终卸载`、`purge` 只作用于目标 `plugin_id` 或 `plugin_id + version`。
3. 最终卸载只会停止目标插件运行时、卸载目标插件动态路由、删除目标插件系统安装记录，并在 `purge=true` 时清理目标版本磁盘产物。
4. PowerX backend、web-admin、数据库、Redis、Event Fabric、Scheduler 服务本身不应因为插件卸载而重启。
5. 其他插件的进程、路由、菜单、租户实例和业务数据不应因为该插件卸载而变化。
6. 页面出现“加载中”通常表示前端正在等待 `/api/v1/admin/plugins/:id/uninstall` 返回，不代表 PowerX 底座正在重启。

## 按钮与状态文案（建议）

- 系统级：
  - 状态：未安装 / 已安装（未启用） / 已启用 / 已停用
  - 按钮：安装（市场页/仅 root）、启用（系统级）、停用（系统级）、重启、切换版本、卸载、查看日志
- 租户级（行内补充）：
  - 状态：未启用（本租户）/ 已启用（本租户）/ 未配置（无记录）
  - 按钮：启用本租户、停用本租户、查看 client_id、轮换密钥、删除本租户配置

## 常见问题（FAQ）

- Q: 为什么启用本租户时没看到明文 secret？
  - A: 仅“首次启用”或“轮换”会返回一次性明文；若记录已存在，启用不会再返回 secret。
- Q: 系统级安装后，租户是否自动启用？
  - A: 否。安装不生成租户凭证，需各租户“启用本租户”后，插件才具备以该租户身份访问宿主的能力。
- Q: 卸载与删除本租户配置的区别？
  - A: 卸载是系统级，影响所有租户并可清理磁盘；删除本租户配置仅影响当前租户的凭证与启用态。
- Q: 轮换密钥后旧的还能用吗？
  - A: 不能。旧 secret 立即失效，请及时分发更新到插件端。

## 敏感操作确认文案（参考）

- 轮换密钥：
  - “此操作将立即使旧凭证失效，未及时更新的插件调用会失败。是否继续？”
- 删除本租户配置：
  - “此操作将删除本租户与该插件的凭证记录。删除后该租户将无法访问该插件，需重新启用生成新密钥。是否继续？”
- 卸载插件（系统级）：
  - “卸载将影响所有租户。是否继续？可选同时清理磁盘产物（不可恢复）。”

## 后端接口（供前端参考）

- 市场（浏览）
  - GET `/api/marketplace/plugins`
- 系统级（root）
  - GET  `/api/admin/plugins/`
  - GET  `/api/admin/plugins/:id/status`
  - GET  `/api/admin/plugins/:id/logs`
  - POST `/api/admin/plugins/install/local`
  - POST `/api/admin/plugins/install/url`
  - POST `/api/admin/plugins/:id/switch_version`
  - POST `/api/admin/plugins/:id/enable`
  - POST `/api/admin/plugins/:id/disable`
  - POST `/api/admin/plugins/:id/restart`
  - POST `/api/admin/plugins/:id/uninstall`
- 租户级（当前租户）
  - GET    `/api/admin/plugins/:id/tenant_config`
  - POST   `/api/admin/plugins/:id/tenant_enable`          // 首次启用返回一次性 secret
  - GET    `/api/admin/plugins/:id/credentials`            // 只读 client_id
  - POST   `/api/admin/plugins/:id/credentials/rotate`     // 一次性返回新 secret
  - DELETE `/api/admin/plugins/:id/tenant_config`          // 删除本租户配置

## 安全与合规建议

- 一次性密钥仅在前端短暂展示；不要写入浏览器本地存储或日志。
- 对轮换/删除/卸载等操作增加二次确认；记录审计日志。
- 插件端保存 `client_id/secret` 到安全位置（ENV、密钥库或受限配置文件），不要持久化短期访问 token（STS）。
