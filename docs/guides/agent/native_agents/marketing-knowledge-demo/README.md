## 先选入口

- 要准备营销复盘的多份 PDF、表格、报告或素材：先打开 `/knowledge-spaces`，在目标空间的“入库”中一次选择多个文件。每个文件会创建独立入库 Job；必须逐个完成并可检索后，才能把它作为后续测试的候选资料。
- 要验证主智能体调度、三个子智能体 handoff 和单消息 Trace：使用 **营销活动复盘协作团队**。
- 要创建或改造团队：先读 [团队编排配置与验收](team-orchestration.md)。团队名称本身不会触发编排；必须具备有效的编排图、成员角色和 Skill 绑定。
- 要实际发起对话、补充材料或追问结论：先读 [团队对话手册](team-conversation-playbook.md)，再进入团队任务。
- 要验证草稿审核和知识库发布：使用 **营销知识采集 Workflow**。
- 要验证某一个智能体绑定的 Skill：进入单智能体会话；它不是团队验收入口。

发布准备团队是专项模板，不是默认营销 Demo。

## 当前营销复盘测试边界

知识库入库和团队复盘是两个连续但独立的测试步骤。当前已发布的营销团队任务图以本轮消息中的结构化材料为权威输入；它不会因为某份文档已入库就自动读取、把它当作事实或绕过本轮来源校验。

因此，当前推荐顺序是：

1. 在知识空间中批量入库资料，确认每个 Job 完成；
2. 在团队任务中粘贴本轮所需的活动目标、口径和指标，明确要求复盘；
3. 检查本轮 Run 的 `outcome`、`reason_code`、Trace 和 V4 证据；
4. 将“团队按授权快照主动读取该知识空间”的场景列为后续 Capability/资源读取接入验收，不能把它误报为当前行为。
