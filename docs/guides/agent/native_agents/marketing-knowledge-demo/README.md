## 先选入口

- 要验证主智能体调度、三个子智能体 handoff 和单消息 Trace：使用 **营销活动复盘协作团队**。
- 要创建或改造团队：先读 [团队编排配置与验收](team-orchestration.md)。团队名称本身不会触发编排；必须具备有效的编排图、成员角色和 Skill 绑定。
- 要实际发起对话、补充材料或追问结论：先读 [团队对话手册](team-conversation-playbook.md)，再进入团队任务。
- 要验证草稿审核和知识库发布：使用 **营销知识采集 Workflow**。
- 要验证某一个智能体绑定的 Skill：进入单智能体会话；它不是团队验收入口。

发布准备团队是专项模板，不是默认营销 Demo。
