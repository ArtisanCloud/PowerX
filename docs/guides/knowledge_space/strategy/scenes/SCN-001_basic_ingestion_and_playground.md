# SCN-001：Simple 策略入库 + Playground 验证（第一条推荐验收场景）

> 目标：用 **A_simple（P0）** 跑通“最小可用闭环”，并在 UI 上看到入库完成 + Playground 可检索结果。

## 策略包模型（A0–O）

- UI 只需要选择“策略包（A0–O）”，场景仅作为“适用范围说明”。
- Profile（P0–P3）是后台预设档位，不再作为 UI 主选项。

### 本场景的唯一选择（Simple）

- 策略包：`A_simple`（Profile P0）

## 适用范围

- 租户业务侧自助（非 admin 帮别人配 UUID）。
- 先验证“默认策略链路是否通”，再逐步引入更复杂的策略与多源同步。

## 前置条件

1. 后端与 Web Admin 已启动，且能正常登录。
2. 当前租户下至少有一个部门可选（如刚执行过 `make db-refresh`，请先退出并重新登录，避免旧 token/ctx 造成部门/空间列表为空）。
3. 至少存在一个可用空间，或你有权限创建空间。

## 测试数据准备（建议）

- 准备一个 1–5 页的 PDF（制度/FAQ/手册均可），内容包含 3–5 个可提问的关键点。
- 准备 1 个简单问题（query），例如：
  - “XX 的流程是什么？”
  - “报销需要哪些材料？”
  - “密码重置怎么做？”

## 步骤 A：创建空间（只创建容器）

1. 进入「知识空间」→ 点击 **新建空间**
2. 填写空间名称（例如：`HR知识库`）
3. 选择所属部门（下拉选择）
4. 点击 **创建空间**
5. 成功后返回「知识空间总览」

**期望结果**
- 总览页列表能看到新空间（可用搜索框按空间名搜索）。

## 步骤 B：入库（Simple 策略）

1. 在「知识空间总览」找到目标空间那一行 → 点击 **入库**
2. 在弹层内选择：
   - 空间：应已自动选中/或手动选择
   - 来源类型：`PDF`（或按实际文件类型）
   - 来源方式：**本地上传**
3. 选择文件后点击 **下一步**
4. 策略包选择：**只选 `A_simple`**
5. 点击 **下一步** → 在分割策略页确认默认值（可覆盖）→ 在确认页点击 **立即入库**

## 分割策略（Segment Defaults）

> 默认值会随“策略包 + 文档格式”变化；可在入库向导第 3 步覆盖。

- 推荐分段模式：`heading`（按结构：标题/段落；无明显结构时按段落）

| Profile 预设 | segmentMode | chunkSize | overlap | 说明 |
| --- | --- | ---:| ---:| --- |
| P0 | `heading` | 1000 | 0 | 最小成本跑通链路 |
| P1 | `heading` | 800 | 120 | 通用默认（推荐） |
| P2 | `heading` | 650 | 160 | 更细粒度，利于证据定位 |
| P3 | `heading` | 700 | 180 | 若启用 KG/层次索引，重叠稍高以保上下文 |

**期望结果**
- 弹层关闭，并提示“入库已提交”。
- 任务进入处理状态，最终变为“完成/完成可检索”。
- 不出现 `[intlify] Not found ...` 之类的缺失 key 告警（如出现，说明前端 i18n 未更新到最新）。

## 步骤 C：Playground 验证检索（Simple 成功标志）

1. 在「知识空间总览」目标空间那一行 → 点击 **Playground**
2. 输入 query（用“测试数据准备”里的问题）
3. 观察返回结果（候选/耗时/降级原因/引用等）

**期望结果**
- 能返回至少 1 条候选与引用（命中你上传的 PDF）。
- 结果中可看到引用来源（页码/段落/片段）。

## Simple 策略在 UI 上“成功”的最小闭环

1. 入库任务状态从“提交/运行”变为“完成”  
2. Playground 能返回命中结果并带引用  
3. 新增第二份文档后仍能命中（不要求新建空间）

## 常见失败与定位

### 1) 401 Unauthorized（空间列表/创建/入库）

- 现象：请求 `POST /api/v1/admin/knowledge-spaces` 或 `POST /api/v1/admin/knowledge-spaces/:id/ingestion-jobs` 返回 401
- 处理：
  - 确认已登录、浏览器里有 `access_token`
  - 如刚 `db-refresh`：退出登录 → 重新登录
  - 确认请求头含 `Authorization`（租户由 JWT claims 提供）（Web Admin 正常会自动注入）

### 2) 部门为空 / 部门树返回空

- 现象：创建空间页部门下拉为空，或接口返回 `data: null`
- 处理：
  - 刷新页面
  - `db-refresh` 后重新登录
  - 后端排查入口：`docs/guides/knowledge_space/runbook.md`

### 3) 503 “No available OpenAI account”

- 含义：触发了需要模型/Provider 的能力，但没有可用账号/路由命中
- 处理：到「AI 设置」配置 provider/账号，并确认租户路由策略生效
