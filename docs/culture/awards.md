## 评选指南
1. **影响力**：对 UUID-only 推进有直接贡献（代码、脚本、运营、客户沟通等）。
2. **协作**：跨团队协调（Ops/DB/CS/Partner）并留下可复用资产。
3. **可验证**：至少提供一个 PR/演练/报告链接。

## 提交流程
1. 提名人填写以下信息并发送至 `people-ops@powerx`：
   ```
   标题：[Nomination] Tenant UUID Champion - <候选人>
   内容：贡献摘要 + 证明链接 + 推荐人
   ```
2. People Ops + VP Eng 审核，确认后在此文档添加记录。
3. All Hands 前 48h 在 Slack #announcements 发布预告，并在会议上颁奖。
