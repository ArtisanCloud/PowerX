# PowerX 多 Agent 产品体验方案（A2A / Multi-Agent）

本文聚焦产品与交互设计层面，展示 PowerX 在单任务多 Agent 协作场景下的用户体验、关键交互、可视化呈现与技术落点指引。

多 Agent 技术落地细节请参见《[PowerX 多 Agent 技术架构方案](./multi_agent_architecture.md)》，可与本篇配套阅读。

## 1. 设计目标

1. **协作透明**：让用户直观看到多名 Agent 的参与顺序、角色分工与输出节奏。
2. **可控可干预**：提供暂停、改派、插入新 Agent 等操作入口，保证用户掌控感。
3. **信息不过载**：在展示增量事件的同时，提供过滤与折叠能力，保持界面清晰。
4. **跨端一致**：桌面端与移动端提供一致的时间线语言与上下文获取方式。

## 2. 页面信息架构（桌面端）

```text
+------------------------------------------------------------------------------------+
| 顶部栏：任务标题 / 状态 / 参与 Agent 标签 / 全局操作（暂停、终止、改派）            |
+---------------------+--------------------------------------------------------------+
| 左侧栏（200px）     | 右侧主体区域                                                |
|---------------------|--------------------------------------------------------------|
| 任务概览卡片        | (A) 协作时间线（默认展开）                                   |
| - 用户输入摘要      |  - 以 Stage 为一级分组，节点按执行顺序排列                  |
| - 目标描述/优先级   |  - 每个节点显示 Agent 头像、角色、耗时、状态                |
| - 计划概览（节点数）|  - 行内展示增量内容（Streaming bubble）                      |
|---------------------|--------------------------------------------------------------|
| Agent 列表/角色      | (B) 任务上下文区                                             |
| - Planner（激活）    |  - Tab1：上下文数据（输入、依赖、变量）                      |
| - Executor（运行中） |  - Tab2：输出汇总（表格/Markdown）                           |
| - Reviewer（待命）   |  - Tab3：插件日志（工具调用、鉴权提示）                      |
|---------------------|--------------------------------------------------------------|
| 插件 & 工具抽屉      | (C) 互动区                                                    |
| - 已启用插件        |  - 聊天框（支持 @Agent 定向发言、追加指令）                  |
| - 可用新插件        |  - Action 按钮（插入 Reviewer、重跑某节点等）                |
+---------------------+--------------------------------------------------------------+
```

## 3. 关键交互流程

1. **实时时间线**：`agent.started/agent.delta/agent.completed` 映射为时间线节点，按 Stage 分段滚动，并列节点通过连接线展示依赖。
2. **节点详情抽屉**：点击任意节点，右侧上下文区切换到“节点详情”，展示输入参数、输出全文、工具调用、重试按钮。
3. **协作提示**：Stage 开始时顶部弹出 Banner（如「Stage 2 · 代码执行 · Executor + PluginX」）；Reviewer 反馈折叠为“审阅摘要”。
4. **异常与恢复**：失败节点以红色卡片突出，提供「重试」「改派给其他 Agent」操作；操作会记录为时间线控制事件（`run.override_plan`）。
5. **插件透明度**：左侧插件抽屉显示调用次数、耗时、权限，支持点击查看详情。

## 4. 移动端响应式策略

- 顶部栏精简为任务标题 + 状态标签，操作按钮折叠为 Action Sheet。
- 时间线改为纵向卡片流，Stage 以手风琴折叠呈现；节点详情使用全屏弹层。
- 左侧栏信息整合到底部 Tab（概览、时间线、上下文、互动）。

## 5. 体验保障与技术落点

- **前端组件**：基于现有聊天面板，新增 `AgentTimeline`、`StageBanner`、`NodeDetailDrawer` 组件；数据复用 SSE 流。
- **状态管理**：在 run store 中扩展 `agentsByStage`、`timelineEvents`、`selectedNode` 等字段。
- **可视化演进**：首版使用卡片 + 状态色，后续迭代 DAG/泳道图，可预留 ECharts/AntV 接口。
- **易用性增强**：提供“只看关键信息”过滤器（隐藏 delta chunk），Streaming 期间保持滚动定位。

---

以上产品体验方案可与《PowerX 多 Agent 技术架构方案》配套实施，确保多 Agent 能力在交互层面同样具备可理解性与可操作性。
